**ChemAI** 是一个面向大学化学实验教学的 AI 智能平台，以 **三草酸合铁(III)酸钾 K₃[Fe(C₂O₄)₃]·3H₂O** 的制备实验为核心，集成 **LLM-RAG 智能问答、知识图谱可视化、语料库文献检索、掌握度自适应测评、实验报告多维评估、深度问题自学习迭代**等功能。

---

## 功能模块

| 页面 | 文件 | 说明 |
|------|------|------|
| **首页入口** | `index.html` | React SPA 首页，身份选择（非化学专业 / 化学专业 / 教师），含 LLM 配置面板 |
| **AI 助手** | `assistant.html` | 多策略检索 + 类比推理引擎 + DeepSeek RAG 问答；**~160 条深度实验操作问答**；10 KP 掌握度自适应测评（苏格拉底式引导）；三维度雷达图 + 掌握度分布直方图 + 综合评语 + 学习建议；**12 条 selfCheck 自动验证规则** |
| **实验手册** | `main.html` | 11 章全文浏览器，LaTeX 公式 Unicode 渲染，响应式布局 |
| **知识图谱** | `knowledge.html` | 97 节点 / 136 关联的 Canvas 交互式配位化学知识网络，节点关联语料库深链 |
| **语料库** | `corpus.html` | **355 篇**中英文文献知识清单，PDF/PPTX/DOCX 上传解析，子领域分布条形图（可点击筛选），**URL 深链定位**，学习迭代报告 |
| **课前预习** | `prep.html` | 多轮对话预习 + 自适应习题检测 + 错题本 |

### 自学习增强机制

- **对抗评分**：5 维度评审（化学正确性 / 定量精确度 / 逻辑完整性 / 教学清晰度 / 实验贴近度）
- **双重评审**（v40+）：首轮评分+主动质疑 → 复核裁定+交叉一致性校验
- **参数锁定校验**：每轮强制对照基准配方（Ksp=3.2×10⁻⁷、6%H₂O₂=1.8M、干燥50°C、失水113°C、Fe=0.01275mol、理论产量6.26g），自动发现并修正自相矛盾处

## 技术架构

### AI 问答流水线 — 智能体集群

```
用户提问
  ↓
阶段 1：多策略检索（BM25 + IDF 加权 + 化学实体类比 + 方法学转移）
  ↓
阶段 2：类比推理引擎（24 组跨体系概念映射）
  ↓
阶段 3：置信度评分 + 混合答案生成（FAQ 直接回答 / 类比桥接 / LLM / 网络回退）
  ↓
阶段 4：自检（12 条验证规则）
```

### 答案展示（v35 重构）

- **统一答案头卡**：置信度徽章 + 来源标签（FAQ/语料库/类比/LLM/网络）
- **固定 icon 章节**：📌 核心解答 → 📖 依据文献 → 🌐 网络补充 → 💡 知识延伸
- **文献卡片深链**：点击直达语料库对应条目（`corpus.html?id=XX`）
- **30 条 ENT_TIPS**：覆盖全部 10 个 KP 核心实体

### 三页深度链接闭环

```
AI 助手 ──文献卡片/引用──→ 语料库（精确定位条目）
    ↑                          ↓
    └──知识延伸── 知识图谱 ──文献关联──┘
```

- `corpus.html` 支持 `?subfield=XX&search=XX&id=XX` URL 参数深链
- 知识图谱节点详情面板关联语料库 subfield，支持跳转 + 强关联加分
- AI 助手文献卡片、引用、知识延伸均带定位参数

## 快速开始

```bash
cd chemai-8.6-
python -m http.server 8080           # Python
# 或
npx serve .                          # Node.js
# 浏览器打开 http://localhost:8080/
```

> ⚠️ 必须通过 HTTP(S) 访问，直接双击 `index.html`（file://）会导致 JSON 数据加载失败。

### 启用 LLM

在「AI 助手」页面左侧 **🤖 LLM AI 配置** 面板中粘贴 DeepSeek API Key 即可。不配置则自动回退本地检索 + 类比推理模式。

## 掌握度测评

10 个 KP（知识点）× 多轮自适应对话 × 苏格拉底式引导：

- **测评报告**：总分 + 等级 + 三维度雷达图 + 掌握度分布直方图 + 综合评语 + 学习建议
- **导出格式**：Word (.doc) / TXT (.txt)
- **题型轮换**：main / alt1 / alt2 交替，防止记忆效应
- **复测机制**：未掌握知识点自动进入复测队列
