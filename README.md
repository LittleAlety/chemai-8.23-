# ChemAI — 三草酸合铁(III)酸钾制备实验 智能教学平台

[![Deploy](https://img.shields.io/badge/GitHub%20Pages-Live-brightgreen)](https://littlealety.github.io/chemai-8.6-/)
[![Version](https://img.shields.io/badge/version-v37-blue)](https://github.com/LittleAlety/chemai-8.6-)
[![FAQ](https://img.shields.io/badge/FAQ-750条-green)](https://github.com/LittleAlety/chemai-8.6-)
[![Corpus](https://img.shields.io/badge/语料库-291篇-orange)](https://github.com/LittleAlety/chemai-8.6-)
[![Deep Qs](https://img.shields.io/badge/深度实验问题-~100条-purple)](https://github.com/LittleAlety/chemai-8.6-)

**ChemAI** 是一个面向大学化学实验教学的 AI 智能平台，以 **三草酸合铁(III)酸钾 K₃[Fe(C₂O₄)₃]·3H₂O** 的制备实验为核心，集成 LLM-RAG 智能问答、知识图谱可视化、语料库文献检索、掌握度自适应测评、实验报告多维评估、**深度操作问答自学习迭代**等功能。

---

## 功能模块

| 页面 | 文件 | 说明 |
|------|------|------|
| **首页入口** | `index.html` | React SPA 首页，身份选择（非化学专业 / 化学专业 / 教师），含 LLM 配置面板 |
| **AI 助手** | `assistant.html` | 多策略检索 + 类比推理引擎 + DeepSeek RAG 问答；**~100 条深度实验操作问答（v36-v37 新增）**；12 知识点掌握度自适应测评（苏格拉底式引导对话），三维度雷达图 + 掌握度分布直方图 + 综合评语 + 学习建议，支持导出 Word/TXT；**12 条 selfCheck 自动验证规则** |
| **实验手册** | `main.html` | 11 章全文浏览器，LaTeX 公式 Unicode 渲染，响应式布局 |
| **知识图谱** | `knowledge.html` | 97 节点 / 136 关联的 Canvas 交互式配位化学知识网络 |
| **语料库** | `corpus.html` | 291 篇中英文文献知识清单，PDF/PPTX/DOCX 上传解析，子领域分布条形图**（可点击筛选）**，学习迭代报告 |
| **课前预习** | `prep.html` | 多轮对话预习 + 自适应习题检测 + 错题本 |

## 深度实验操作知识体系（v36-v37 新增）

v36-v37 通过 **4 个并行 Agent 集群 + 对抗评分代理** 生成、审计并插入约 100 条深度实验操作 FAQ，覆盖：

| 操作步骤 | 深度问题数 | 典型问题示例 |
|----------|:---------:|-------------|
| 称量溶解 | ~6 | 加酸顺序颠倒的后果、莫尔盐变黄的产率修正、自来水 Ca²⁺/Mg²⁺ 干扰 |
| 沉淀(第一步) | ~10 | 草酸倒入顺序、一次性倒入爆发成核、陈化过头副作用、冷水洗涤损失、BaCl₂ 漏检风险、灰绿色沉淀诊断、倾滗不彻底定量损失 |
| 氧化(第二步) | ~10 | H₂O₂ 过量/不足、煮沸时间、滴加位置、磁力搅拌参数、忘加 K₂C₂O₄ 的不可逆性、Fenton 反应链式浪费 |
| 配位(第三步) | ~8 | 微沸 vs 40°C、体积过浓爆发成核、草酸过量分析干扰、滴速过快局部酸伤、60°C 慢配可行性 |
| 结晶(第四步) | ~12 | 乙醇慢加 vs 快加、搅拌时长上限、冰箱冷藏副作用、棉线异相成核、70%/95%/无水乙醇对比、丙酮/乙醚禁忌、静置时间、晶种诱导 |
| 抽滤干燥 | ~8 | 检漏方法、滤纸润湿密封原理、定性 vs 定量滤纸、过抽应力裂纹、80°C 禁用原因、硅胶再生、热样品称量误差 |
| 安全与废液 | ~6 | 铁氰化钾+酸=HCN、母液与乙醇分类排放、乙醇闪点与爆炸极限、水浴交叉污染监测 |
| 数据处理 | ~5 | Q 检验+RSD、天平预热漂移、恒重判据由来、莫尔盐纯度校正、有效数字传递 |

### 对抗评分自学习循环（v37.5）

- **生成**: 30 条全新深度操作问题，覆盖 10 个未探索领域
- **评分**: 对抗代理逐题评分（5 维度：正确性/精确性/逻辑/清晰度/相关性）
- **结果**: 23/30 正确，净 +23 分（76.7%）
- **修正**: 6 个系统性错误被识别并修复（Ksp 2.1→3.2×10⁻⁷、Dean 涡→混沌平流、6% H₂O₂ 2.0→1.8M 等）

## 技术架构

### AI 问答流水线 — 智能体集群

```
用户提问
  ↓
阶段 1：多策略检索
  ├─ 直接关键词搜索语料库（BM25 + IDF 加权）
  ├─ 化学实体类比检索（同子领域相似结构/性质条目）
  └─ 方法学转移检索（相同操作术语跨体系匹配）
  ↓
阶段 2：类比推理引擎
  ├─ 比较问题术语与已知概念库（24 组类比映射）
  ├─ 识别跨化学体系的模式（K₃[Fe(C₂O₄)₃] → K₃[Cr(C₂O₄)₃] 等）
  └─ 无直接匹配时生成"通过类比"桥接解释
  ↓
阶段 3：置信度评分 + 混合答案生成
  ├─ 语料库命中高 → FAQ 直接回答 + 文献引用（折叠卡片）
  ├─ 命中低但类比存在 → 类比桥接 + 网络检索链接
  └─ 无命中 → LLM 回答（如已配置 DeepSeek API）或网络回退
  ↓
阶段 4：自检（12 条验证规则）
  └─ d⁵自旋态混淆、虚构KCl杂质、pH沉淀条件矛盾、
      温度混淆(50°C vs 110°C)、废液直排、H₂O₂浓度错误等
```

### 答案展示优化（v35-v36）

- **统一的答案头卡**: 置信度徽章（高/中/低）+ 来源标签（FAQ/语料库/类比/LLM/网络）
- **固定 icon 章节**: 📌 核心解答 → 📖 依据文献 → 🌐 网络补充 → 💡 知识延伸
- **文献卡片精简**: 300→150 字摘录，折叠展示
- **网页搜索紧凑化**: 大卡片 → 一行 pill 按钮栏
- **视频推荐过滤**: 按操作关键词过滤 17 个视频资源
- **30 条 ENT_TIPS**: 覆盖全部 10 个 KP 核心实体

## 快速开始

```bash
cd chemai-8.6-
python -m http.server 8080           # Python
# 或
npx serve .                          # Node.js
# 浏览器打开 http://localhost:8080/
```

> ⚠️ 必须通过 HTTP(S) 访问，直接双击 `index.html`（file://）会导致 JSON 数据加载失败。

### 启用 LLM

在「AI 助手」页面左侧 **🤖 LLM AI 配置** 面板中粘贴 DeepSeek API Key 即可。不配置则自动回退本地检索 + 类比推理模式。

## 掌握度测评

10 个 KP（知识点）× 多轮自适应对话 × 苏格拉底式引导：

- **测评报告**: 总分 + 等级 + 三维度雷达图 + 掌握度分布直方图 + 综合评语 + 针对性学习建议
- **导出格式**: Word (.doc) / TXT (.txt)
- **题型轮换**: main/alt1/alt2 三种题型交替出现，防止记忆效应
- **复测机制**: 未掌握的知识点自动进入复测队列
